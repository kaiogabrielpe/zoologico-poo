# Zoologico - Lista 2 (POO)

Sistema em Java para gerenciar um zoologico, desenvolvido para a Lista 2 da disciplina de Programacao Orientada a Objetos. O projeto aplica os conceitos de heranca e polimorfismo: diferentes tipos de animais (Gato, Cachorro e Passaro) sao implementados como subclasses de uma classe base Animal, e todos sao armazenados e manipulados por meio dessa superclasse comum. O sistema permite cadastrar, listar e remover animais, alem de emitir seus sons e testar suas habilidades, tudo por meio de um menu interativo no terminal.
